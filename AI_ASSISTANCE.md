# KI-Unterstützung / AI assistance / Assistance par IA

## Deutsch

PII Redaction wird mit Unterstützung von KI-Werkzeugen entwickelt, vor allem mit Claude Code (Anthropic). Die KI hilft beim Schreiben von Code, Tests und Dokumentation.

Der Maintainer prüft, testet und verantwortet jede Änderung selbst. Jede Änderung läuft durch die Qualitäts-Gates (Lint, Typprüfung, Unit- und Integrationstests) und wird auf echten Nextcloud-Instanzen getestet, bevor sie veröffentlicht wird. Die Nextcloud-Richtlinie für KI-Beiträge gilt: https://github.com/nextcloud/.github/blob/main/AI_POLICY.md

## English

PII Redaction is developed with the help of AI tools, mainly Claude Code (Anthropic). The AI assists with writing code, tests and documentation.

The maintainer reviews, tests and takes responsibility for every change. Every change passes the quality gates (lint, type checks, unit and integration tests) and is tested on real Nextcloud instances before it is released. The Nextcloud AI contribution policy applies: https://github.com/nextcloud/.github/blob/main/AI_POLICY.md

## Français

PII Redaction est développé avec l'aide d'outils d'IA, principalement Claude Code (Anthropic). L'IA aide à écrire le code, les tests et la documentation.

Le mainteneur vérifie, teste et assume la responsabilité de chaque modification. Chaque modification passe les contrôles de qualité (lint, vérification des types, tests unitaires et d'intégration) et est testée sur de vraies instances Nextcloud avant d'être publiée. La politique de Nextcloud sur les contributions assistées par IA s'applique : https://github.com/nextcloud/.github/blob/main/AI_POLICY.md
