# Installer PII Redaction

1. Activer AppAPI et configurer un démon de déploiement (HaRP recommandé).
2. Installer PII Redaction depuis la section External Apps de l'App Store.
3. Les réglages se trouvent dans Paramètres d'administration, Paramètres supplémentaires.
